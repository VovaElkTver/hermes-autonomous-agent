## Решение Вл по noop-порогу (21.11)

Число 3 (одинаковых причин) — **условный порог**, не константа веры: жизнь покажет
калибровку по живым step_noop-событиям. Вектор развития намечен: счётчик-инкремент
может смениться таймстамп-параметризацией ("уже час сижу" честнее, чем "пятый раз
сидел"). Смена — policy-level чтение, не миграция схемы: ctl_event уже несёт ts на
каждый noop, данные для времени копятся с первого дня.
