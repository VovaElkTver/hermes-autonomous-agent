# Журнал

Документ самодисциплины агента и данные для третьей стороны. Append-only: строки только добавляются, никогда не правятся и не удаляются.

Протокол (Вл, 31.10):
1. Намерение записывается дословно (текст задания Вл + все уточнения до «начал работу»), без пересказа агентом и без критериев приёмки от агента.
2. Исполнение. Результат append-ится к записи.
3. Пакет критику: первоначальное намерение + все предыдущие вердикты критику + ответы/замечания + новый результат.
4. Безусловное принятие критиком = задание выполнено. Иначе — append новых намерений по замечаниям, исполнение, шаг 3. Цикл до безусловного принятия.

Файл на задание: `journal/<UTC>-<slug>.md`, секции append-ом: `## НАМЕРЕНИЕ`, `## РАУНД N — РЕЗУЛЬТАТ`, `## РАУНД N — ВЕРДИКТ КРИТИКА` (дословно), `## РАУНД N — НАМЕРЕНИЯ ПО ЗАМЕЧАНИЯМ`.
