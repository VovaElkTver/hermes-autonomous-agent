# Журнал

Документ самодисциплины агента и данные для третьей стороны. Append-only: строки только добавляются, никогда не правятся и не удаляются. Гарантию неизменности несёт агент: любая ошибка исправляется новой корректирующей append-записью, не правкой старой.

## Изложение протокола агентом по дословным цитатам Вл (31.10–01.11.2026, см. секции НАМЕРЕНИЕ записей)
1. Намерение записывается дословно (текст задания Вл + все уточнения до «начал работу»), без пересказа агентом и без критериев приёмки от агента.
2. Исполнение. Результат append-ится к записи.
3. Пакет критику: первоначальное намерение + все предыдущие вердикты + намерения по замечаниям + новый результат.
4. Безусловное принятие критиком = задание выполнено. Иначе — append новых намерений по замечаниям, исполнение, шаг 3. Цикл до безусловного принятия.

Файл на задание: `journal/<дата>-<slug>.md`. Секции append-ом: `## НАМЕРЕНИЕ`, `## ГРАНИЦА НАМЕРЕНИЯ`, `## РАУНД N — РЕЗУЛЬТАТ`, `## РАУНД N — ВЕРДИКТ КРИТИКА`, `## РАУНД N — НАМЕРЕНИЯ ПО ЗАМЕЧАНИЯМ`.
